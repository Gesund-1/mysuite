# MySuite 1.1.1

## Pembaruan Aplikasi
- Menambahkan navbar tetap di bagian atas setiap module dengan tombol Home untuk kembali ke halaman utama MySuite.
- Memperbaiki navigasi tombol Back Android agar saat module terbuka kembali ke Home, bukan menutup aplikasi.
- Memperbarui Plugin Manager untuk mendukung Import, Update, dan Hapus plugin.
- Memperbarui ikon aplikasi dan logo header MySuite.
- Menyamakan target kompilasi Java dan Kotlin ke JVM 17.

## Build
APK debug dibuat melalui GitHub Actions pada `.github/workflows/android.yml`.
